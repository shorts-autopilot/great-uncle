# Spec schema (v1)

Generated from the grandMA3 v2.2 web manual by `tools/crawl/crawl.py`.
Everything is UTF-8 JSON, keys are stable, and IDs never encode array indexes
except the `sNN` section suffix, which is ordinal within its topic.

## `spec/manual.json`

```jsonc
{
  "meta": {
    "product": "Console-X",
    "source": "https://help.malighting.com/grandMA3/2.2/",
    "toc_url": "…/_webHelpScripts/Master/toc_nav.js",
    "manual_version": "2.2",
    "toc_nodes": 1223,        // every node in the manual's tree
    "unique_topics": 1223,    // unique page (external id) count
    "parsed_topics": 1223,
    "failed_topics": 0
  },
  "tree":  [ /* raw TOC nodes as published: {id, t, c: [...], vals: {e: "ext_id"}} */ ],
  "nodes": [
    {
      "toc_id": "357857",          // stable id from the manual's TOC (string)
      "ext_id": "news",            // page basename; null for the manual root
      "title": "New in the Manual",
      "depth": 1,                  // 0 = manual root, 1 = chapter, …
      "order": 0,                  // position among siblings
      "parent_toc_id": "357679",
      "path": ["grandMA3 User Manual"]  // ancestor titles, root first
    }
  ],
  "topics": {
    "cue_sequence_settings": {
      "ext_id": "cue_sequence_settings",
      "url": "https://help.malighting.com/grandMA3/2.2/HTML/cue_sequence_settings.html",
      "doc_title": "…",
      "blocks": [
        {"type": "heading",  "level": 2, "text": "Label"},
        {"type": "para",     "text": "…"},
        {"type": "note",     "text": "Hint: …"},
        {"type": "list",     "items": [{"text": "Auto Start", "depth": 0}]},
        {"type": "table",    "headers": ["…"], "rows": [["…", "…"]]},
        {"type": "code",     "text": "…"},
        {"type": "image",    "src": "…", "alt": "…"}
      ],
      "sections": [
        {
          "heading": "Start",       // null for the introduction
          "level": 2,
          "items": ["Auto Start", "…"],  // list items, table rows, short labels
          "notes": ["Hint: …"]
        }
      ],
      "links": [{"text": "Cues and Sequences", "ext_id": "cue_sequence"}],
      "counts": {"blocks": 117, "headings": 6, "tables": 1, "notes": 0, "links": 12}
    }
  }
}
```

`blocks` is the lossless reading order; `sections` is the same content grouped
under headings, which is what the matrix consumes.

## `spec/topics.jsonl`

One JSON object per TOC node, in document order:

```jsonc
{"toc_id":"…","ext_id":"…","title":"…","path":["…"],"depth":2,
 "url":"…","headings":["…"],"counts":{"blocks":12,"headings":3,…}}
```

## `spec/matrix.json`

```jsonc
{
  "meta": {
    "product": "Console-X",
    "source": "…/toc_nav.js",
    "manual_version": "2.2",
    "row_count": 1223,
    "section_count": 4881,
    "status_vocabulary": ["not-started","in-progress","implemented","verified","out-of-scope"]
  },
  "chapters": [
    {"chapter":"Cues and Sequences","chapter_ext_id":"cue_sequence",
     "module":"playback","phase":2,"scope":"product",
     "topics":19,"sections":120,"items":640}
  ],
  "rows": [
    {
      "id": "CX-CUE_SEQUENCE-0007",   // stable feature id: CX-<chapter>-<nnnn>
      "kind": "topic",                // topic | keyword | option-keyword | lua-function
                                      // (sections only appear in "children")
      "name": "Store Cues",
      "path": ["grandMA3 User Manual","Cues and Sequences","Store Cues"],
      "chapter": "Cues and Sequences",
      "module": "playback",           // target subsystem in our codebase
      "phase": 2,                     // delivery phase from the build plan
      "scope": "product",             // product | hardware | meta | legal
      "status": "not-started",
      "source": {"ext_id":"cue_store","url":"…","toc_id":"…"},
      "token": "…",                   // keyword/option rows only
      "signature": "…",               // lua-function rows only
      "children": [
        {"id":"CX-CUE_SEQUENCE-0007.s01","kind":"section","name":"Label",
         "level":2,"items":["Name","Scribble"],"notes":[],"truncated":false}
      ]
    }
  ]
}
```

Rules:
- `status` is the only field implementation work should rewrite; everything else
  is derived from the manual and regenerated by the crawler.
- `phase`/`module` come from `CHAPTER_MAP` in `tools/crawl/crawl.py`; change them
  there, not in the JSON.
- `scope: hardware` rows describe consoles, nodes and wings, not software.
  They are kept for completeness but are not product backlog.

## Regenerating

```bash
python3 tools/crawl/crawl.py            # full, resumable
python3 tools/crawl/crawl.py --offline  # re-derive from the HTML cache only
```
